Обвести и найти

Обведите что угодно на скриншоте — и найдите это в Google.

Искать, не выходя из приложения

  1. Добавьте командуОдна кнопка — откроются «Команды», нажмите «Добавить».
  2. Назначьте двойное касаниеНастройки → Универсальный доступ → Касание → Касание задней панели → Двойное касание → «Поиск».
  3. Стукните дважды по задней крышкеПоиск откроется поверх приложения. Обведите → «Искать». «Готово» — вы там же, где были.
Добавить команду
Собрать команду вручную
  1. «Команды» → + → по порядку: Сделать снимок экрана → Изменить размер (ширина 720) → Кодировать в base64 (разрывы строк: нет) → Текст: https://drakahell.github.io/iPhone-Search/#img= + «Кодированный Base64 файл» → Открыть веб-просмотр.
  2. При первом запуске iOS спросит разрешение — выберите «Разрешать всегда».
Без команды: выбрать скриншот вручную

Откроется в Safari. Сделайте скриншот и выберите его — он будет первым в списке.

Добавить на экран «Домой»: «Поделиться» → «На экран „Домой“». Убрать — удерживайте значок → «Удалить закладку».

Отключить — удалите команду в «Командах». Скриншот уходит только в Google и только после «Искать».
