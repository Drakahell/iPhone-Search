Обвести и найти

Обведите что угодно на скриншоте — и найдите это в Google.

Как пользоваться

  1. Сделайте скриншотБоковая кнопка + громкость вверх.
  2. Откройте эту страницу«Выбрать скриншот» → он будет первым в списке.
  3. Обведите пальцемТо, что хотите найти, — и нажмите «Искать».
Добавить на экран «Домой»

В Safari нажмите «Поделиться» → «На экран „Домой“». Появится значок, как у приложения. Чтобы убрать — удерживайте значок → «Удалить закладку». Больше ничего не остаётся.

Искать, не выходя из приложения

Добавить готовую команду

Двойное касание по задней крышке — и поиск открывается в шторке поверх текущего приложения. Нажали «Готово» — вы там же, где были.

  1. «Команды» → + → добавьте по порядку (ищите через поиск снизу): Сделать снимок экрана → Изменить размер изображения (ширина 1080) → Кодировать в Base64 (перенос строк: нет) → Текст: https://drakahell.github.io/iPhone-Search/#img= + «Результат Base64» → Показать веб-страницу (если её нет — Быстрый просмотр).
  2. Настройки → Универсальный доступ → Касание → Касание задней панели → Двойное касание → эта команда.

Изображение отправляется только в Google и только когда вы нажмёте «Искать».
