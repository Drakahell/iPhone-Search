# Как раздавать приложение другим людям

Для пользователей установка выглядит так: **открыл ссылку → поставил TestFlight из App Store →
нажал «Установить»**. Без компьютера, без Sideloadly, без переустановки каждые 7 дней.

Без платного аккаунта Apple это сделать нельзя: на iPhone приложения ставятся только из App Store
и TestFlight. Остальные способы требуют компьютера и подходят только для разработчика.

| Способ | Для пользователя | Что нужно вам |
|---|---|---|
| **TestFlight** (рекомендую начать с него) | ссылка → «Установить» | Apple Developer Program, $99/год |
| **App Store** | найти в App Store → «Загрузить» | то же + проверка Apple (обычно 1–3 дня) |
| Sideloadly (как сейчас) | компьютер, кабель, Apple ID, раз в 7 дней | ничего |

Одна сборка TestFlight работает 90 дней. Новую сборку получает каждый, кто установил по ссылке.
Публичная ссылка выдерживает до 10 000 человек.

## Настройка (один раз, ~30 минут)

### 1. Аккаунт разработчика
[developer.apple.com/programs/enroll](https://developer.apple.com/programs/enroll) — вступить как
частное лицо. Одобрение занимает от нескольких часов до пары дней.

### 2. Придумать идентификатор приложения
Например `com.ivanov.circlesearch` — латиница, должен быть уникальным во всём App Store.

### 3. Создать приложение в App Store Connect
[appstoreconnect.apple.com](https://appstoreconnect.apple.com) → «Приложения» → **+** → «Новое приложение»:
- платформа iOS, название «Обвести и найти» (или своё);
- **Bundle ID**: если вашего идентификатора нет в списке, сначала зарегистрируйте его на
  [developer.apple.com → Identifiers](https://developer.apple.com/account/resources/identifiers/list)
  → **+** → App IDs → App → Explicit, ввести идентификатор из шага 2;
- SKU — любое слово, например `circlesearch`.

### 4. Ключ для автоматической выгрузки
App Store Connect → «Пользователи и доступ» → «Интеграции» → «Ключи App Store Connect API» → **+**:
- имя любое, доступ **App Manager**;
- скачайте файл `AuthKey_XXXXXXXXXX.p8` (скачать можно только один раз!);
- запишите **Key ID** и **Issuer ID** (вверху страницы).

**Team ID** — на [developer.apple.com/account](https://developer.apple.com/account) → «Membership details».

### 5. Передать всё это GitHub
Репозиторий → **Settings → Secrets and variables → Actions**.

Вкладка **Secrets** → «New repository secret», четыре штуки:

| Имя | Что вставить |
|---|---|
| `APPLE_TEAM_ID` | Team ID |
| `ASC_KEY_ID` | Key ID |
| `ASC_ISSUER_ID` | Issuer ID |
| `ASC_PRIVATE_KEY` | всё содержимое файла `.p8` (открыть Блокнотом и скопировать целиком) |

Вкладка **Variables** → «New repository variable»:

| Имя | Значение |
|---|---|
| `BUNDLE_ID_PREFIX` | идентификатор из шага 2 |

Секреты GitHub никому не показывает — даже в публичном репозитории.

### 6. Выгрузить сборку
Вкладка **Actions** → **TestFlight** → **Run workflow**. Через 15–30 минут сборка появится в
App Store Connect → ваше приложение → TestFlight.

### 7. Ссылка для пользователей
App Store Connect → TestFlight → «Внешнее тестирование» → **+** создать группу → добавить сборку →
ответить на вопросы для проверки (первая сборка проверяется Apple, обычно меньше суток) →
**включить публичную ссылку**. Эту ссылку и раздавайте.

## Что увидит пользователь
1. Открывает ссылку → ставит TestFlight → «Установить».
2. При первом запуске разрешает доступ к фото (одна кнопка).
3. Дальше: **скриншот → открыть приложение** — поиск начинается сам.
   Или: миниатюра скриншота → «Поделиться» → «Обвести и найти» — не выходя из своего приложения.

## Готовая команда для касания задней панели (по желанию)
1. Соберите команду: «Сделать снимок экрана» → «Обвести и найти».
2. В «Командах» нажмите на неё и удерживайте → «Поделиться» → «Скопировать ссылку iCloud».
3. Вставьте ссылку в `AppConfig.backTapShortcutURL` (файл `Kit/Core/Settings/AppSettings.swift`).

После этого у пользователей в приложении появится кнопка «Добавить готовую команду».
