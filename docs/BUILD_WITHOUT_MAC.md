# Сборка и тестирование без Mac (с Windows)

Xcode работает только на macOS, поэтому компиляция идёт на облачном Mac.
Схема: **Windows (пишем код) → GitHub (облачный Mac собирает и тестирует) → iPhone (ставим приложение)**.

## Шаг 1. Залить проект на GitHub

1. Зарегистрируйтесь на [github.com](https://github.com) и создайте пустой репозиторий (`New repository`).
   - **Public** — облачный Mac бесплатен без ограничений, но код будет открыт.
   - **Private** — бесплатно ~200 минут macOS в месяц (минуты macOS считаются ×10). Одна сборка ≈ 10–15 минут.
2. В папке проекта выполните (подставьте свой адрес репозитория):

```bash
git init -b main
```

```bash
git add . && git commit -m "Initial commit"
```

```bash
git remote add origin https://github.com/ВАШ_ЛОГИН/CircleSearch.git
```

```bash
git push -u origin main
```

## Шаг 2. Собрать и прогнать тесты

После push сборка запускается сама: вкладка **Actions** в репозитории → workflow **iOS**.
- Зелёная галочка — проект компилируется и юнит-тесты проходят.
- Красный крестик — откройте шаг «Сборка и тесты»: там ошибки компилятора с номерами строк.
  Скопируйте их в чат — я исправлю.
- Внизу страницы запуска — артефакты: логи, результаты тестов и `CircleSearch-unsigned-ipa`.

## Шаг 3. Установить на iPhone

### Вариант А — бесплатно, Sideloadly (Windows)
1. Установите [Sideloadly](https://sideloadly.io) и iTunes (версию с сайта Apple, не из Microsoft Store).
2. Скачайте артефакт `CircleSearch-unsigned-ipa` из GitHub Actions и распакуйте zip.
3. Подключите iPhone кабелем, перетащите `.ipa` в Sideloadly, войдите своим Apple ID, нажмите **Start**.
4. На iPhone: Настройки → Основные → VPN и управление устройством → доверять разработчику.
   На iOS 16+ также включите Настройки → Конфиденциальность → **Режим разработчика**.

Ограничения бесплатного Apple ID:
- приложение нужно переустанавливать каждые **7 дней**;
- не более 3 приложений одновременно (расширение «Поделиться» может считаться отдельным);
- общие App Groups и Keychain между приложением и расширением могут не заработать —
  тогда ключ Google будет виден только в самом приложении.

### Вариант Б — надёжно, TestFlight ($99/год, Apple Developer Program)
Подписанная сборка, установка через TestFlight без кабеля, срок 90 дней, все возможности
(App Groups, Visual Intelligence) работают как в App Store. Для этого в workflow добавляется
шаг подписи и загрузки — сделаю, когда будет аккаунт разработчика.

## Что и где тестировать

| Что | Где |
|---|---|
| Компиляция, юнит-тесты (геометрия, разбор ответов Google) | GitHub Actions, автоматически |
| Оверлей, жесты, анимации, выдача Google | только на iPhone |
| Visual Intelligence | iPhone 15 Pro и новее, iOS 26+, Apple Intelligence включён |

## Альтернативы GitHub Actions
- **Codemagic** — облачные Mac, есть бесплатные минуты, поддерживает XcodeGen.
- **Аренда облачного Mac** (почасово) — полноценный удалённый рабочий стол с Xcode и симулятором,
  если нужно смотреть интерфейс на симуляторе.
